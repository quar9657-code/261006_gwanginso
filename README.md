# 광주 인스타 연구소

정적 HTML 사이트입니다. 빌드나 서버용 API 키 설정 없이 실행할 수 있습니다.

```sh
python3 -m http.server 8000 --directory .
```

브라우저에서 `http://localhost:8000`을 열거나 정적 호스팅에 저장소를 게시하세요.

## AI 상담원

1. 페이지의 **AI 상담** 메뉴로 이동합니다.
2. Google AI Studio에서 발급받은 본인의 Gemini API 키를 입력합니다.
3. 가게 소개나 고민을 입력하고 **상담 보내기**를 누릅니다.

모델은 요청된 `gemini-3.5-flash-lite`를 사용합니다. 브라우저가 Google Gemini REST API의 `v1beta/models/gemini-3.5-flash-lite:generateContent`에 직접 요청하며, 키는 `x-goog-api-key` 헤더로 전달됩니다. 해당 모델의 제공 여부와 접근 권한은 사용자의 Google 계정에서 확인해야 합니다. 모델이 없거나 접근할 수 없으면 오류를 안내하며 다른 모델로 자동 변경하지 않습니다.

키와 대화는 브라우저 페이지 메모리에서만 유지되고 로컬 스토리지, 쿠키, 저장소에 저장하지 않습니다. **키 지우기**는 키와 대화를 지우고 진행 중인 요청을 취소합니다. 새로고침해도 모두 지워집니다. **대화 초기화**는 키를 유지하고 대화만 지웁니다. Google에 전송된 요청은 취소나 초기화로 회수되지 않습니다.

전송 시 상담 내용과 최근 10회 대화가 Google에 전달되고 해당 API 키의 요금·할당량이 적용됩니다. AI 답변은 텍스트로 표시하며 견적·계약·예약 또는 성과를 확정하지 않습니다. 공개 사이트에는 운영자 공용 키를 코드에 넣지 마세요.

브라우저 검증은 API 응답을 모의해 대화 이력, 오류 처리, 취소, 초기화, 키 미저장, 모바일 화면과 메뉴·FAQ·상담 준비 복사 기능을 확인했습니다. 실제 Gemini 응답은 유효한 API 키로 별도 확인해야 합니다.

## 사이트 구성

광주 대표님들의 자립을 중심으로 프로그램 소개, 사명, 광인소의 자체 미디어 운영, 호남문화관광주간 홍보 콘텐츠 참여를 소개합니다. `1.png`는 기존 프로그램 소개 위치의 수업 사진, `2.JPG`는 첫 화면의 계정 운영 실습 사진, `Image_20260930_100506_444.jpeg`는 사명 섹션의 상담 사진입니다. 차분한 주황색 포인트와 크림색 배경, 따뜻한 차콜색을 사용합니다. AI 상담원의 프로그램 정보는 `assets/chat.js`의 안내 내용과 함께 관리합니다.
